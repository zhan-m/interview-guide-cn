# 面试指南（中文版）

欢迎来到 Nick 的[面试指南](https://interviewguide.dev)！

我叫 Nick，是一名 senior software engineer。我以候选人和面试官两种身份参加过约 100 场软件工程师面试，通过过 big tech / FAANG 公司以及一些初创公司的面试。

这份指南是我把自己有立场（opinionated）的面试流程整理出来分享给软件开发社区。

## 本地预览

```bash
yarn install
yarn docs:dev   # 开发模式，http://localhost:5173
yarn docs:build # 构建静态站，产物在 docs/.vitepress/dist/
```
