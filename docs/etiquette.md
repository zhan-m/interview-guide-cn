# 面试礼仪

<star />

## 好礼仪是必需

我反复惊讶于有多少候选人靠**糟糕礼仪**自毁前程。面试是你**展示最佳状态**的时刻。公司知道这一点——既然你"最佳"也礼仪不佳，他们会假设你日常更糟。

## 几条要记在脑后的事

照例，这不是一份穷尽清单，但应该能让你 get 到要点：

- **准时到。** 我把"提前 5 分钟"作为合适的到场时间（不论现场还是远程）。远程的话，提前测试一切、并确保你**至少**准点登录。现场则有更多风险：堵车、地铁延误等。我个人宁愿在面试旁边吃午饭或喝咖啡半小时，**也不冒着迟到的险**。
- **感谢对方花的时间。** 做面试官是辛苦的、协调面试也是辛苦的。感谢所有人（recruiter、coordinator、interviewer）。**这是对的事**，也会让你**显得**很好。
- **友好、感恩、积极。** 态度在面试里**极其**重要。我们花太多时间在攻克编码题上，反而忘了我们在**和人**打交道。**表现得像一个面试官想与之共事的人**。
- **别批评公司或它的流程。** 你问公司或项目如何运作时，可能会注意到某些做法在你看来**不是**最佳实践。**没关系**——他们这么做大概率有原因；如果没有，也许将来你可以帮忙改善！但你**不该**告诉面试官"你们得改"。**这真的会发生！** 除非面试官**明确邀请**你这么做（比如"我们在【x】这块有困难，我想听听你会怎么做"），否则别这样。
- **了解公司、它的价值观、以及你将做什么。** 每家公司都希望被当成"特别"的。花 30 分钟读公司价值观、了解你将参与的产品，**值得**。
- **诚实/坦率。** 你为了套题硬编故事，**对方一眼能看出**。希望每道行为题你都有例子，没有也没关系——尽量转成假设题答（比如"我可能没有完全契合的过去经历，但我大致会这样处理这种情况……"）。
- **问能体现你对岗位兴趣的问题。** 问团队如何运作、产品在组织愿景里的位置——任何让你看起来对岗位感兴趣的问题。注意：希望你**真的**感兴趣，但**至少**你得让对方**觉得**你感兴趣。

## 礼仪是双向的

面试也是**公司**展示自己最佳状态的机会。如果你感到被不尊重或不公对待，**记下来**。如果他们对正在**追求**的候选人都这样，那对**员工**可能更糟。
