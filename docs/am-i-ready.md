# 我准备好开始面试了吗？

<star />

## 这不是一个 yes/no 问题

这是一个**特别**常见的问题。但它其实**不是**一个 yes/no 问题。

一个准备很少的人也可能走运：他可能恰好碰上一场和他已知/刚学的内容完全对口的面试。反过来，一个准备充足的人可能特别倒霉，或者那天状态糟糕。

## 犹豫的时候就去面

只要你**稍微**觉得自己准备过，就**冲**。最坏会怎样？没拿到 offer。那种情况下：

- 你积累了一段宝贵的经验
- 你大概率可以 6–12 个月后再投同一家公司
- 你克服了对失败的恐惧（如果你正好有这毛病）

犹豫的时候就去面！
