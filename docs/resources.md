## Leetcode 风格面试

搞定那些恼人的算法/编码题：

| 资源                     | 描述                                                                                                                                                   | 链接                                                  |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------- |
| Leetcode                 | 这类面试得名于此。我认为你大部分练习应该在这里完成。                                                                                                   | [Link](https://leetcode.com)                          |
| Neetcode                 | 用这份清单练 **Neetcode 150** 和 **Blind 75**。                                                                                                          | [Link](https://neetcode.io/practice)                  |
| Neetcode YouTube channel | Leetcode 题解里堪称神作。Neetcode 清单里也都关联了对应视频。                                                                                            | [Link](https://www.youtube.com/c/NeetCode)            |
| Grind 75                 | Blind 75 的作者后来又出了一份新清单和一个能帮你规划学习的网站。我自己没用过，但看起来不错。                                                            | [Link](https://www.techinterviewhandbook.org/grind75) |
| Big O Cheatsheet         | Leetcode 题里最常用算法的时间和空间复杂度速查表。                                                                                                       | [Link](https://www.bigocheatsheet.com/)               |
