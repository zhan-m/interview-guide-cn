# 价值观面（Values Interviews）

<star />

## 什么是价值观面？

价值观面和行为面相似，但**不要**混淆。把两者搞混很容易，尤其当它们在同一场 session 里同时进行时。

很多公司都有公开的 core values。比如 Google 的 [Ten things we know to be true](https://about.google/philosophy/)。如果你应聘的公司有 core values，你应该预期会被对照这些价值观评估。所以**值得专门准备**。

## 怎么准备价值观面

只有当你知道目标公司是哪家时，才能真正开始准备价值观面。我的建议是：在面试**前一周内**准备价值观这部分。好消息是——价值观面准备起来其实**相对简单**。

### 在行为面准备的基础上叠加

你应该已经做了行为面的准备。回顾一下你的行为面故事，针对公司价值观稍作调整。当然不要撒谎，只是确保**显式**点出公司的价值观。

举例：我有一段经历是改造工具链让项目实现真正的 continuous deployment。如果我应聘的公司有"Fail faster and iterate"这样的价值观，我会在 CD 故事里**直接点名**这条价值观。

### 把公司的 core values 写下来或打印出来

把 core values 摆在面前能帮你记起来。面试官不会介意你印一份在手边——反而会觉得你做了功课、对这家公司很认真。

### 把 core values 作为你"为什么来"的理由（如果属实）

我猜你认同任何你应聘公司里的若干 core values。公司常会问"你为什么想加入我们？"——这是**完美时机**点出与你共鸣的 core values！
