# 面试前的沟通

<star />

## Recruiter 是你的朋友

面试前你大部分接触的人是 recruiter（有时还有一位单独的 coordinator）。

对于面试这件事来说，**recruiter 是你的朋友**。建议你带着"他们希望你成功"的心态和他们打交道。这意味着你应该向他们提那些**能帮你成功**的问题！

## 应该问什么

面试前你应该问 recruiter 不少问题。下面是适用于现场和远程面试的一份非穷尽清单：

### 现场或远程面通用

- 如果他们没主动告诉你，问着装要求
- 问你会有哪几轮面试。行为面？Leetcode？实战编码？知识点？价值观？很多人惊讶于"原来这也能问"——其实大多数情况下 recruiter 会告诉你具体有哪几轮，甚至会告诉你**顺序**。
- 问编码轮（如果有的话）能不能用你最熟的语言。一般可以，但也可能公司有指定的语言或框架。
- 问实战编码轮可不可以**上网**。

### 现场

- 确认时间和地点。如果你需要乘飞机或其他公司付费交通工具，确认行程和联系人。
- 提前一两天再次确认面试，确保没有变动。

### 远程

- 问会用什么视频软件。**提前几天**下载并测试好。
- 如果有编码环节，问它怎么进行：是本地开发 + 分享屏幕？还是用 CodeSandbox 这样的共享在线环境？不论答案是什么，**用相同环境提前练习**。

## 做一个**好人**

我见过太多候选人因为粗鲁或不礼貌**自毁前程**。做好人不光在面试轮里有用——和 recruiter 打交道时也算数。尊重他人本就是对的事，附带的好处是：你拿到 offer 的机会更大。设想两位技术水平完全相同的候选人，一位看起来很友好、很好共事，另一位有点像 jerk——你会给谁 offer？
