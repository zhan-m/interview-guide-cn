# 去哪里面试？

<star />

## 看你自己

你应该去哪里面试，很大程度取决于你的个人偏好。你想要 FAANG（Facebook、Apple、Amazon、Netflix、Google）那种"声望"吗？想去 big tech？还是明确**不想**进 big tech？想避开 Leetcode 风格的面试吗？

## 面试 big tech

FAANG / big tech 有利有弊。优势之一：简历上挂着"Google"或"Apple"会打开很多机会的门——你之后投递的回应率会大幅提高。

当然，big tech 也有劣势。这些公司体量大，你可能没法做出在小公司或创业公司那样大的影响。另外，你可能受不了它们的 bureaucracy（官僚气）。

面试方式上，FAANG 和 big tech 倾向于用 Leetcode 风格的题。如果你不想做 Leetcode，那就该把目光投向别处。

## 做有依据的决定

考察某家公司时，[Glassdoor](https://www.glassdoor.com/) 是你的朋友！用它查潜在雇主的评分和面试流程。

想知道某家公司的薪酬大概是多少，用 [levels.fyi](https://levels.fyi)。它众包整理了公司员工的薪资信息。

## 犹豫时就投

如果你在投不投、面不面之间犹豫，我的建议是：**直接投**。最坏情况，你也练了手；最好情况，你拿到 offer，要么接受、要么作为另一份 offer 的谈判筹码。
