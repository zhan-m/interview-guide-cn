这个问题被问得很多：<a href="https://neetcode.io/practice" target="_blank">NeetCode 150</a> 这份清单**够**你通过软件工程师面试吗？

答案因人而异，但大体上我会说："**够，前提是你方法用对**。"

# 用对方法的话，NeetCode 150 是够的

我这里**不打模糊**：我认为 NeetCode 150 **足以**作为面试 leetcode 部分的准备。但前提是——你得**用对方法**。可惜很多人**练错了方法**，然后疑惑为什么面试表现不佳。

下面几节我会讲怎么**正确地**用 NeetCode 150 做准备。

## 做 NeetCode 150 时该做的事

- **每题先自己花 20–30 分钟尝试，再看题解。** 太早放弃直接看题解，无法训练你大脑的"问题解决"部分。
- **看了题解后，强迫自己脱开题解再写一遍。** 看完题解很容易告诉自己"嗯，我懂了"，但其实你**不一定真的完全懂**，往往也记不住。看完题解后，**让自己再写一遍**直到 leetcode 标记 "Accepted"。
- **看了题解的题，过段时间必须再做一遍。** 如果你只在看题解后才解出某题，你不知道自己**是不是真的会**。把所有借助过题解的题**bookmark**，几天后再做一遍，确保**没帮助也能解出来**。
- **练习边做边讲（出声）。** 很多人觉得这很搞笑，但**必须做**！你**绝不该**让真实面试是你**第一次**边解题边解释思路！这个技能对大多数人都很难，强烈建议把它**纳入日常练习**。
- **轮换题目分类。** 很多人犯一个错——**一个分类做完再做下一个**。这样问题在于：等你做完较后的分类时，**早期分类已经忘了**。建议用**轮换策略**——比如先把每个分类的 easy 都做完，再做 medium，最后 hard。

# 仍然有运气成分

一点坏消息：你即便练了 5000 题，仍然可能碰到解不出的题，或者那晚没睡好、或者什么意外让面试变差。**练 leetcode 永远不能保证你通过面试**，它只是**提高成功概率**。

# 还有其他类型的编码题，尤其在你做 niche 方向时

如果你方向偏 frontend、quant 等 niche，**千万别只刷 NeetCode 150**。比如 frontend 岗位面试很可能会涉及 HTML、CSS、JavaScript 和 DOM 操作。

# 面试不止"拿下编码题"

最后一条：**确保你的面试准备是全面的**。你即便是世界上最强的 leetcoder——如果你不为讲述自己的工作经历做准备、行为题答得糟糕、或者为人粗鲁，**你大概率拿不到 offer**。

# 结论

NeetCode 150 是一份**优秀**的资源，**大体上**足以让你通过 leetcode 风格的面试。**前提是**你**方法对**！而且即便你把 leetcode 部分干得漂亮，还有**很多其他类型**的面试要准备。
