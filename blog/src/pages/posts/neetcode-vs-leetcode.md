刚开始备战技术面试的人，常常分不清 **NeetCode** 和 **Leetcode** 这两个服务。它们都是帮你准备编程面试的，但**各有侧重**。

本文讲清两者的差别。

# 为什么需要 NeetCode 或 Leetcode？

它们能帮我们准备编程面试，**很好地抓住**了科技公司常考的某一类题的精髓。

# 什么是 Leetcode？

[Leetcode.com](https://leetcode.com) 是一个有**上千道**编码题的网站。在网站上你可以做难度从 Easy → Medium → Hard 的题。

Leetcode 提供免费账号，免费版功能就很丰富，足以让你做核心的"刷编码题"。下图是 Leetcode 上一道题的样子：

![solving a leetcode problem](/images/leetcode-solve.jpg)

Leetcode 还有一些训练版块，教你数据结构、算法和问题解决技巧。

除了免费功能外，Leetcode 还提供 premium 会员。会员能解锁更多题目和实用功能——比如按"该题在某公司被问的频次"排序。

Leetcode 题已经成为编码面试里**最流行**的题型之一，尤其是 big tech 和 FAANG 公司。

# 什么是 NeetCode？

记得我说 Leetcode 有**上千道题**吗？对大多数开发者（包括我自己）来说，备战面试时**那是太多了**。

**NeetCode 登场！** [NeetCode.io](https://neetcode.io) 是一位软件工程师做的网站，目标是给你一份**精选**——从 Leetcode 里选出 150 道题练。这些题被组织进以下分类：

- Arrays & Hashmaps
- Two Pointers
- Sliding Windows
- Stack
- Binary Search
- Linked List
- Trees
- Tries
- Heap / Priority Queue
- Backtracking
- Graphs
- Advanced Graphs
- 1-D Dynamic Programming
- 2-D Dynamic Programming
- Greedy
- Intervals
- Math & Geometry
- Bit Manipulation

他不仅提供精选清单，还提供**文字题解**和**优秀的视频讲解**——告诉你**怎么**解每一道题。

NeetCode 帮太多人通过了面试，作者最近又开了**付费版**——包含课程和额外内容。我没订过这个付费版，但鉴于他**免费**内容的质量，我相信付费版也物有所值。

# 把 NeetCode 和 Leetcode 一起用

任何人备战技术面试时，我经常建议：**把 NeetCode 当作清单和指南，直接在 Leetcode 上做题**。这样你既享受了 NeetCode 的精选清单和讲解，又在 Leetcode 上获得了实打实的**键盘练习**。
