你终于对自己的能力有了信心、准备好参加面试、投了一堆简历……然后**毫无回音**。这很扎心，我懂。这是一个敏感话题，但**值得反思**为什么你拿不到面试。

# 这是个 numbers game：你投得够多吗？

第一件事是：**找工作本质上是个 numbers game**。如果你只投了一两份、甚至十份简历，**远远不够**！即便最有经验的工程师投这么少也不会有回音。

不一定是这些公司觉得你不够格——很可能是其他**很多**事：

- 这几家公司岗位**已招到人**，但 JD 还挂着
- 你投递那天，候选人**已经选定**
- 简历筛选员**没看懂**你的经历就 pass 了你
- 简历筛选员**没资格**评估软件工程师候选人
- 你简历的某些地方没吸引到筛选员
- 上面几条**叠加发生**

你要投**很多**岗位，因为上面这些情况**都很容易发生**。**如果你投了 50+ 份还没回音**，再开始考虑"是不是有别的问题"。**在那之前——继续投**！

# 你的简历**第一眼看不出特别**

从公司角度看也是 numbers game——一个岗位他们可能收到**几百份**简历。

你的申请/简历**有什么让你脱颖而出**？

如果你寄望于他们会去看你的 GitHub 项目、觉得你做过有意思的事——**别想了**。现实是大多数简历筛选员**没时间**去看候选人的 GitHub。他们读简历**1–2 分钟**就决定要不要进入下一份。

简历能脱颖而出的方式有几种：

- 在 big tech 或 FAANG（Facebook、Amazon、Apple、Netflix、Google）工作过
- 之前的工作经历和岗位**直接相关**
- 候选人在业余做了**独特**的事来展示热情
- 与岗位相关的**学位**（在你没工作经验时尤其有用）

**你符合上面任何一条吗？** 如果都不符合，你的简历很难脱颖而出。

如果是这样，**别太灰心**——你可以**主动**采取一些行动让自己更显眼！

## 如何让自己脱颖而出

"没在 big tech 工作过"或"没学位"这两件事你做不了什么。所以更合理的策略是：**做一些业余的事**展示你的热情。几个想法：

- 给一个或多个开源项目贡献。把它加到简历里，把简历 headline 写成 "Software engineer and open source contributor"。
- 开一个软件工程主题的博客或网站。写到简历里。
- 发布一个你熟悉的语言的库/包。
- 录视频教程，把频道链接放到简历里。
- 部署一个 app/网站，并在简历里列出。

这些事**不只是 GitHub 上的项目**——它们展示了你"超出本职"的对软件工程的兴趣，可能正好是你需要的"脱颖而出"那一下。

# 别停止投递

不论你打算怎么提升自己被筛选员注意到的概率，**关键是别停止投递**。即便你在改简历的路上，**也要继续投**——这是个 numbers game。**祝你好运！**
